README - KHREOR FASHION CONTACT PAGE
=======================================

FILE
----
index(6).html

OVERVIEW
--------
This is a standalone HTML contact page for Khreor Fashion. It provides
customers with direct email contacts for different departments and includes
a main executive contact section.

The page uses embedded HTML and CSS and does not require separate CSS,
JavaScript, images, or external libraries.

FEATURES
--------
- Responsive viewport setup for desktop and mobile devices.
- Clean, modern contact page design.
- Khreor Fashion branding in the page title and heading.
- Department-based contact directory.
- Clickable email addresses using mailto links.
- Seven customer/business contact departments.
- Executive contact section.
- Hover effects on cards and email links.
- Embedded CSS for easy installation and portability.

DESIGN
------
The page uses a light background, white content card, dark text, subtle
borders, rounded corners, and hover effects.

Main CSS colors include:
- Primary: #111827
- Primary hover: #374151
- Background: #f9fafb
- Card background: #ffffff
- Main text: #1f2937
- Secondary text: #4b5563
- Border: #e5e7eb

HOW TO OPEN
-----------
1. Keep the file as "index(6).html", or rename it to "index.html".
2. Double-click the HTML file to open it in a web browser.
3. Compatible modern browsers include Chrome, Firefox, Edge, and Safari.
4. Click an email address to open the visitor's default email application.

HOW TO PUBLISH
--------------
For a website:
1. Rename the file to "index.html" if required by your hosting provider.
2. Upload it to your website hosting/public HTML directory.
3. Open your website domain in a browser.

CUSTOMIZATION
-------------
You can edit the file using Visual Studio Code, Notepad++, or another
text/code editor.

To change contact information, update both the visible email address and
the corresponding mailto="..." link.

To change the design, edit the CSS variables near the beginning of the
<style> section.

IMPORTANT
---------
This page does not contain a backend, database, contact form processor,
payment system, or JavaScript functionality.

Email addresses use "mailto:" links, meaning the visitor's device will
attempt to open its configured email application.

The page is self-contained and does not depend on external assets.
